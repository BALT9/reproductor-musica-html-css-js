Modulo 1: Git y Github

Aprende control de versiones
y trabajo colaborativo con git

Ver estado de los archivos: git status

Añadir cambios: git add <archivo>

Confirmar cambios: git commit -m "mensaje"

Subir cambios a GitHub: git push

Actualizar repositorio local: git pull

Modulo 2: Docker

Aprende a contenerizar aplicaciones
y administrar contenedores de manera eficiente

Inscribete Ahora

Ver contenedores activos: docker ps

Iniciar contenedor: docker run <imagen>

Detener contenedor: docker stop <id>

Eliminar contenedor: docker rm <id>

Ver imágenes locales: docker images

Modulo 4: Laravel

Construye aplicaciones web robustas con PHP

Inscribete Ahora

Crear un nuevo proyecto Laravel:
composer create-project laravel/laravel nombre_proyecto

Ingresar al proyecto:
cd nombre_proyecto

Levantar servidor de desarrollo:
php artisan serve

Ver rutas definidas:
php artisan route:list

Crear un controlador:
php artisan make:controller NombreControlador

Modulo 4: Spring Boot

Construye aplicaciones web robustas con Java

Inscribete Ahora

Crear un nuevo proyecto Spring Boot:
curl https://start.spring.io/starter.zip -d dependencies=web -d name=demo -o demo.zip

Descomprimir el proyecto:
unzip demo.zip -d demo

Ingresar al proyecto:
cd demo

Levantar servidor de desarrollo:
./mvnw spring-boot:run

Construir proyecto:
./mvnw clean package

Modulo 4: Node - NestJS

Construye aplicaciones web robustas con Node.js

Inscribete Ahora

Crear un nuevo proyecto NestJS:
nest new nombre_proyecto

Ingresar al proyecto:
cd nombre_proyecto

Levantar servidor de desarrollo:
npm run start

Generar un módulo:
nest generate module nombre_modulo

Generar un controlador:
nest generate controller nombre_controlador
